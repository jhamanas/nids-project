# tests/

Unit tests for the project's Python modules (currently: `preprocessing/pcap_parser.py`).

## Running

```bash
pip install -r requirements.txt
python -m pytest tests/ -v
```

## Fixtures

`fixtures/sample.pcap` is a small synthetic capture (7 packets) generated by
`scripts/generate_test_pcap.py` — it exists so the parser can be tested before
the real, registration-gated CICIDS2017 PCAPs are downloaded. It covers:

- An HTTP GET request split across two TCP segments, plus a retransmitted
  duplicate of the first segment (tests session reassembly + overlap handling)
- An HTTP response
- A DNS query (UDP) — intentionally has no Raw-layer payload, since DNS is
  parsed by scapy into its own DNS layer, not Raw; this is what you'd want
  to special-case if you extend the parser to cover DNS payloads explicitly
- A payload with a repeated-byte pattern, structurally distinct from the
  HTTP text, for testing byte-level features later in Phase 3
- A one-packet FTP control-channel payload

Regenerate it any time with:
```bash
python scripts/generate_test_pcap.py
```

Once real CICIDS2017 PCAPs are available, add a second, real-data-based test
module rather than replacing this one — the synthetic fixture is still useful
for fast, deterministic tests that don't depend on a multi-GB download.
